WOKRIEN RESSEL v6 — ЮMoney + Supabase

Что уже сделано:
- реальные общие товары и сток через Supabase;
- защищённая админка по email/паролю;
- таблица заказов в админке;
- корзина с несколькими предметами;
- создание заказа на сервере;
- переход на официальную страницу оплаты ЮMoney;
- выбор: банковская карта или кошелёк ЮMoney;
- уникальный label для каждого заказа;
- HTTP webhook ЮMoney;
- проверка нового sign через HMAC-SHA256;
- проверка currency / unaccepted / суммы заказа;
- автоматическое списание стока ТОЛЬКО после подтверждённой оплаты;
- защита от повторной обработки одного webhook;
- страница success.html со статусом заказа;
- светлая тема Cinnamoroll / тёмная Kuromi.

============================================================
ВАЖНО: НИКАКИЕ ПАРОЛИ И СЕКРЕТЫ В ФАЙЛЫ САЙТА НЕ ВСТАВЛЯТЬ
============================================================

Публично в config.js находятся только:
- SUPABASE_URL
- SUPABASE_ANON_KEY

Секрет ЮMoney хранится только в Supabase Edge Function Secrets.

============================================================
ШАГ 1. SUPABASE
============================================================

1. Создайте бесплатный проект Supabase.

2. SQL Editor -> New query.

3. Выполните весь файл:
   supabase_schema.sql

4. Authentication -> Users -> Add user.
   Создайте своего администратора по email + паролю.

5. После создания пользователя снова откройте SQL Editor и выполните:

   insert into public.admin_users(user_id)
   select id from auth.users
   where email = 'ВАШ_EMAIL'
   on conflict (user_id) do nothing;

6. Project Settings -> API.
   Возьмите:
   - Project URL
   - anon/public key

7. Вставьте их в config.js.

============================================================
ШАГ 2. SUPABASE CLI
============================================================

Нужен Supabase CLI.

После установки войдите:

supabase login

В папке проекта:

supabase link --project-ref ВАШ_PROJECT_REF

============================================================
ШАГ 3. СЕКРЕТЫ EDGE FUNCTIONS
============================================================

Выполните:

supabase secrets set YOOMONEY_RECEIVER=НОМЕР_ВАШЕГО_КОШЕЛЬКА
supabase secrets set SITE_URL=https://ВАШ-САЙТ.pages.dev
supabase secrets set YOOMONEY_NOTIFICATION_SECRET=СЕКРЕТ_ИЗ_НАСТРОЕК_HTTP_УВЕДОМЛЕНИЙ_ЮMONEY

Не добавляйте YOOMONEY_NOTIFICATION_SECRET в config.js.

============================================================
ШАГ 4. DEPLOY EDGE FUNCTIONS
============================================================

Выполните:

supabase functions deploy create-order --no-verify-jwt
supabase functions deploy order-status --no-verify-jwt
supabase functions deploy yoomoney-webhook --no-verify-jwt

Почему --no-verify-jwt:
- create-order и order-status вызываются публичным магазином;
- webhook вызывается серверами ЮMoney, у которых нет Supabase JWT;
- безопасность webhook обеспечивается обязательной HMAC-SHA256 подписью ЮMoney;
- записи в базу выполняются только серверной функцией.

============================================================
ШАГ 5. HTTP-УВЕДОМЛЕНИЯ ЮMONEY
============================================================

После deploy адрес webhook будет:

https://ВАШ_PROJECT_REF.supabase.co/functions/v1/yoomoney-webhook

В ЮMoney:
1. Откройте настройки HTTP-уведомлений.
2. Укажите этот HTTPS URL.
3. Сохраните/скопируйте секрет уведомлений в Supabase Secrets.
4. Нажмите кнопку тестирования уведомлений.

Новый параметр sign проверяется через HMAC-SHA256.
Секрет не должен попадать в браузер.

============================================================
ШАГ 6. БЕСПЛАТНЫЙ САЙТ
============================================================

Статические файлы можно разместить на Cloudflare Pages.

Пример:
https://wokrien-ressel.pages.dev

В SITE_URL у Supabase должен быть ИМЕННО ваш реальный адрес сайта,
без завершающего "/".

============================================================
КАК ПРОХОДИТ ПОКУПКА
============================================================

1. Покупатель кладёт предметы в корзину.
2. Нажимает "Оплатить заказ".
3. Выбирает карту или кошелёк ЮMoney.
4. create-order проверяет товары и цену в базе.
5. Сервер создаёт ORDER с уникальным label.
6. Браузер POST-запросом переходит на yoomoney.ru/quickpay/confirm.
7. Покупатель оплачивает.
8. ЮMoney отправляет webhook.
9. Edge Function проверяет HMAC-SHA256 sign.
10. Сверяется withdraw_amount с суммой заказа.
11. Сток списывается атомарно.
12. ORDER получает статус paid.
13. success.html показывает "Оплата подтверждена".

Если к моменту оплаты сток неожиданно закончился:
- деньги не игнорируются;
- заказ становится paid_manual_review;
- он выделяется в админке и требует ручной обработки.

============================================================
ПРО КОМИССИЮ
============================================================

ЮMoney сообщает:
- withdraw_amount — сколько заплатил отправитель;
- amount — сколько фактически зачислено получателю после комиссии.

Wokrien Ressel проверяет цену заказа именно по withdraw_amount,
потому что это сумма, которую заплатил покупатель.

============================================================
ПЕРЕД РЕАЛЬНЫМИ ПРОДАЖАМИ
============================================================

Сделайте тестовый платёж на небольшую сумму и проверьте:
- order появился;
- webhook пришёл;
- status стал paid;
- stock уменьшился;
- operation_id сохранился.

Не выдавайте цифровой товар только по факту возврата на success.html.
Единственный источник подтверждения оплаты — проверенный webhook ЮMoney.
